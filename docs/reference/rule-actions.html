clientSocket.socketSetting Socket Setting Specifies a socket setting for the client TCP socket (can be specified multiple times with each rule action specifying another socket setting)

remoteEndpoints.netInterface Network Interface Specifies the network interface that provides a binding host address for all remote endpoints
remoteEndpoints.socketSetting Socket Setting Specifies a socket setting for all remote endpoints (can be specified multiple times with each rule action specifying another socket setting)
routeSelectionLogAction Log Action Specifies the logging action to take if a route ID is selected
routeSelectionStrategy Selection Strategy Specifies the selection strategy for the next route ID
selectableRouteId String Specifies the ID for a selectable route (can be specified multiple times with each rule action specifying another ID for a selectable route)
