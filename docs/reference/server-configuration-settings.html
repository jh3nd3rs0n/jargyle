Chaining General Settings

Name Value Type Description
chaining.routeId String The ID for a route through a chain of other SOCKS servers. This setting also marks the current other SOCKS server as the last SOCKS server in the chain of other SOCKS servers
chaining.socksServerSocket.bindHost Host The binding host name or address for the other SOCKS server TCP socket
Default Value: 0.0.0.0
chaining.socksServerSocket.bindHostAddressTypes Host Address Types The comma separated list of acceptable binding host address types for the other SOCKS server TCP socket
Default Value: HOST_IPV4_ADDRESS,HOST_IPV6_ADDRESS
chaining.socksServerSocket.bindPortRanges Port Ranges The comma separated list of binding port ranges for the other SOCKS server TCP socket
Default Value: 0
chaining.socksServerSocket.connectTimeout Non-negative Integer The timeout in milliseconds on waiting for the other SOCKS server TCP socket to connect (a timeout of 0 is interpreted as an infinite timeout)
Default Value: 60000
chaining.socksServerSocket.netInterface Network Interface The network interface that provides a binding host address for the other SOCKS server TCP socket
chaining.socksServerSocket.prepareSocket Boolean The boolean value to indicate if the other SOCKS server TCP socket is to be prepared before connecting (involves applying the specified socket settings, resolving the other SOCKS server host name, and setting the specified timeout on waiting to connect)
Default Value: false
chaining.socksServerSocket.socketSettings Socket Settings The comma separated list of socket settings for the other SOCKS server TCP socket
chaining.socksServerUri SOCKS Server URI The URI of the other SOCKS server

Default Value: 1.2.840.113554.1.2.2

Default Value: false

Default Value: true
chaining.socks.gssapiauthmethod.suggestedInteg Integer The suggested quality-of-protection (i.e. integrity) value for GSS-API messages sent after GSS-API authentication with the other SOCKS server (applicable if the negotiated protection level is SELECTIVE_INTEG_OR_CONF)
Default Value: 0
chaining.socks.methods Comma Separated Values The comma separated list of acceptable authentication methods to the other SOCKS server
Default Value: NO_AUTHENTICATION_REQUIRED
chaining.socks.socksDatagramSocket.clientInfoUnavailable Boolean The boolean value to indicate if the client information expected to be used to send UDP datagrams (address and port) is unavailable to be sent to the other SOCKS server (an address and port of all zeros is sent instead)
Default Value: false
chaining.socks.socksHostResolver.resolveFromSocksServer Boolean The boolean value to indicate if host names are to be resolved from the other SOCKS server
Default Value: false
chaining.socks.userpassauthmethod.password String The password to be used to access the other SOCKS server
chaining.socks.userpassauthmethod.username String The username to be used to access the other SOCKS server
